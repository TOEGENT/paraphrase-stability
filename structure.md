# Структура проекта

Дерево ниже отражает **текущее состояние рабочей папки**. Кэши Python, виртуальное окружение, вложенные `.git` и содержимое рабочих JSONL не показаны.

```text
paraphrase-stability/
├── configs/                         # настройки моделей и экспериментов
├── data/
│   └── examples/                    # небольшие примеры формата данных
├── datasets/
│   ├── DefAn/
│   │   ├── DefAn-public/            # исходные публичные вопросы
│   │   ├── DefAn-Public Combined/    # объединённый набор
│   │   └── Images/                  # изображения из набора
│   └── mathematics_dataset/         # клонированный генератор DeepMind
│       └── mathematics_dataset/
│           ├── modules/             # типы задач: алгебра, матан и др.
│           ├── sample/              # числа, многочлены и деревья выражений
│           └── util/                # составные задачи и форматирование
├── paper/                            # черновики статьи
├── scripts/
│   └── README/                       # инструкции по маршрутам и ролям
├── src/
│   └── slm_answer_stability/
│       ├── annotation/               # заготовка модуля разметки
│       ├── data/                     # заготовка модуля данных
│       ├── evaluation/               # анализ ошибок
│       ├── generation/               # заготовка модуля генерации
│       └── models/                   # эмбеддинги, MLP и обучение
├── tests/                            # тесты кода проекта
└── work/                             # локальные файлы запусков
```
