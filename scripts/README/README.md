# Выбор пайплайна

- [100 структурных перефразов линейного уравнения: разбор, преобразования, проверка](README_LINEAR_PARAPHRASES.md)
- [Математический датасет: генерация уравнений, проверка ответов и устойчивость](README_MATH.md)
- [Нематематический датасет: вопросы, перефразы, LLM-судья и устойчивость](README_NOT_MATH.md)

В математическом маршруте по умолчанию каждый ответ становится якорем, и `k/N` вычисляется относительно остальных ответов на то же уравнение. В нематематическом маршруте эквивалентность оценивает AI-судья, а `compute_k_N.py --original-only` оставляет якорем исходный вопрос. Все команды выполняются из корня репозитория; существующие выходные файлы и каталоги скрипты не перезаписывают.
