# Роль 5: новая область задач

## Что происходит

Эта роль ищет тип вопросов за пределами готовых линейных уравнений, для которого можно создавать много вариантов и проверять, что ответ не изменился. Подходящий пример — перевод единиц измерения: можно менять запись чисел и единиц, но нужно сохранить одно физическое значение и то, что спрашивается.

```text
выбрать область → создать исходные вопросы → придумать правила вариантов → проверить ответы → пилот
```

## Что уже можно запустить

`generate_math_tasks.py` показывает темы Mathematics Dataset и создаёт исходные задачи, например по измерениям:

```powershell
uv run python scripts/generate_math_tasks.py --list-topics
uv run python scripts/generate_math_tasks.py --topic measurement --count 20 --seed 42 --format structured --output work/measurement_sources_20.jsonl
```

Это команды **только для исходных задач**. В текущем `work` нет файла `measurement_sources_20.jsonl` и нет проверенного JSONL вариантов новой области. Нельзя выдавать пример выходного файла за результат уже состоявшегося запуска.

## Проблема и задача

Генератор линейных вариантов `generate_linear_equation_variants.py` проверяет решения линейных уравнений и к измерениям, вероятности или арифметике не подходит. Человеку этой роли нужно сравнить несколько областей, выбрать одну, определить допустимые преобразования и независимую проверку ответа, затем сделать пилот из 20 исходных вопросов и 3–5 проверенных вариантов на каждый. Нужно посчитать дубли, отклонённые и неоднозначные варианты, а уже потом предлагать большой прогон роли 2. Подробный план: `scripts/README/README_NEW_DOMAIN_TASK.md`.
