# Results management

## Что сохраняем

Для каждого запуска сохраняются:
1. Использованная конфигурация (`configs/*.yaml` + commit SHA).
2. Таблицы метрик (CSV/JSON).
3. Графики (калибровка, распределения ошибок, сравнение по типам преобразований).

## Правила

- Не перезаписывать результаты: использовать уникальные run-id/временную метку.
- Явно фиксировать `model_version_id` и `protocol_version_id` рядом с метриками.
- Отдельно маркировать промежуточные и итоговые результаты MVP-недели.
- Не хранить в Git крупные артефакты и веса моделей (см. `.gitignore`).
