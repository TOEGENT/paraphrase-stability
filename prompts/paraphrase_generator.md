# Инструкция генератору преобразований вопроса

Задача: создать семантически эквивалентные преобразования вопроса без изменения намерения пользователя.

Требования:
1. Сохранять исходный смысл вопроса.
2. Не добавлять новые факты/ограничения.
3. Не удалять существенные условия вопроса.
4. Генерировать варианты разных типов преобразования (лексические, синтаксические, стилистические).
5. Для каждого варианта возвращать:
   - `task_id`
   - `variant_id`
   - `transformation_type`
   - `question_original`
   - `question_transformed`

Формат вывода: JSONL, одна запись на вариант.
