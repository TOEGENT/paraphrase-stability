# Abstract

Language models can give different answers to questions that express the same request in different words. Measuring this variation for each question requires generating meaning-preserving paraphrases, running the model again, and comparing the resulting answers. This study investigates whether the stability of a fixed small language model can be predicted before those additional runs. We define answer stability as **k/N**: among N reviewed paraphrases, k produce answers semantically equivalent to the model's original answer. The measure describes agreement with that answer, which may itself be incorrect.

The work has three components. First, we define a review protocol for constructing stability labels from paraphrased questions and their answers. Second, we train a multilayer perceptron on embeddings of only the original question and its answer; paraphrases supply training labels but are unavailable at inference time. Third, we propose to evaluate the predictor on unseen questions against constant and simpler learned baselines, measuring prediction error, calibration, ranking for selective review, and cost relative to direct measurement. If validated, the predictor could prioritize question–answer pairs for full paraphrase testing; it would not replace that testing or establish answer correctness.
