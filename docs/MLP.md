# Обучение MLP для прогнозирования устойчивости ответа

MLP обучаем предсказывать долю эквивалентных переформулировок, на которые фиксированная SLM отвечает тем же смыслом, что и на исходный вопрос.

Разметку получаем непосредственными проверками; при применении достаточно одной пары «вопрос–ответ».

## 1. Фиксируем условия

Выбираем:

- SLM;
- системную инструкцию;
- greedy decoding;
- лимит ответа.

Проверяем воспроизводимость одинакового промпта.

Задаём правила генерации перефразов: сохранять информацию, требования и ограничения задачи, менять только форму. Прогноз будет относиться именно к этому распределению перефразов.

## 2. Собираем данные для каждой задачи

Для исходного вопроса $q$:

1. Получаем исходный ответ $a=M(q)$.
2. Создаём $N$ эквивалентных вопросов $q'_1,\ldots,q'_N$.
3. Проверяем сохранение смысла вопросов; изменившие задачу варианты исключаем или заменяем.
4. Получаем ответы $a'_i=M(q'_i)$.

Исходная пара — вход будущего предиктора. Остальные пары нужны для разметки.

## 3. Размечаем сохранение смысла ответа

Отдельный оценщик сравнивает каждый $a'_i$ с исходным $a$, учитывая вопрос $q$.

| Метка | Значение |
|---|---|
| **1 — эквивалентны** | Совпадают существенные утверждения, условия, отрицания, числа и оговорки |
| **0 — различаются** | Есть существенное смысловое различие |
| **Неясно** | Недостаточно уверенности для решения; требуется ручная проверка |

Для длинных ответов можно сначала выделять ключевые утверждения **независимо для каждого ответа**, сохраняя существенные детали.

Сжатие и оценщик проверяются на вручную размеченной выборке. Правильность ответа не влияет на метку эквивалентности.

## 4. Вычисляем целевую метку

После разрешения неясных случаев:

$$
y=\frac{k}{N},
\qquad
k=\sum_{i=1}^{N}\mathbf{1}[a'_i\equiv a].
$$

Например, из 20 проверочных ответов 14 эквивалентны исходному:

$$
y=0{,}70.
$$

Исходный ответ не включаем в число проверочных ответов.

Сохраняем не только долю, но и $k$, $N$, решения оценщика и тексты:

| Поле | Пример |
|---|---|
| `task_id` | `0042` |
| `question` | Исходный вопрос |
| `answer` | Исходный ответ SLM |
| `equivalent_count` | `14` |
| `paraphrase_count` | `20` |
| `target` | `0.70` |

## 5. Готовим признаки

Начальный вариант:

$$
x=[E(q);E(a)],
$$

где $E$ — фиксированная модель эмбеддингов, а точка с запятой обозначает конкатенацию.

Эмбеддинги предварительно вычисляем и сохраняем. **Проверочные перефразы и их ответы не подаём на вход MLP.**

Все данные одной исходной задачи помещаем в одну часть: `train`, `validation` или `test`. Любое снижение размерности обучаем только на `train`.

## 6. Обучаем MLP

Начальная архитектура, где $d$ — размерность одного эмбеддинга:

```text
Эмбеддинги вопроса и ответа
→ Linear(2d, 64)
→ ReLU
→ Dropout(0.1)
→ Linear(64, 1)
→ Sigmoid
```

Выход $\hat y$ — прогноз сохранения смысла.

Если для всех примеров одинаковое $N$, можно использовать MSE либо бинарную кросс-энтропию с мягкой меткой $y=k/N$.

Если $N$ различается, можно использовать биномиальную функцию потерь, с точностью до постоянного относительно модели слагаемого:

$$
L=-k\log\hat y-(N-k)\log(1-\hat y).
$$

Она придаёт больший вес примерам с большим количеством проверок. Её вероятностная интерпретация предполагает независимые выборки перефразов.

Начальные настройки:

| Параметр | Значение |
|---|---|
| Оптимизатор | AdamW |
| Learning rate | $10^{-3}$ |
| Batch size | 32 |
| Остановка | Early stopping по validation loss |

Окончательные настройки выбираем по валидации.

## 7. Проверяем результат

На новых задачах сравниваем MLP с:

- постоянным прогнозом;
- регуляризованной линейной регрессией на тех же признаках.

Измеряем:

- **MAE** — среднюю абсолютную ошибку прогноза;
- **калибровку** — соответствуют ли прогнозы около 0,7 фактической доле около 0,7.

Для части тестовых задач собираем больше независимых перефразов: **метка по 20 вариантам сама является шумной оценкой, а не точной вероятностью.**

## Итог

Дорогие перефразы и сравнения нужны при создании обучающих меток.

После обучения новый вопрос и один ответ превращаются в прогноз того, как часто эквивалентные переформулировки сохранят смысл этого ответа.

**Устойчивость смысла не равна правильности ответа.**
