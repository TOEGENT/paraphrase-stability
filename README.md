# paraphrase-stability

Predicting semantic answer stability under meaning-preserving prompt transformations from a single question–answer pair in small language models.

## Цель проекта

Проект **slm-answer-stability** оценивает вероятность того, что при семантически эквивалентном преобразовании вопроса фиксированная SLM (с **greedy decoding**) сохранит смысл ответа.

## Постановка задачи

- Вход для предиктора: одна пара *(исходный вопрос, исходный ответ SLM)*.
- Целевая метка устойчивости: **k/N**, где:
  - **N** — число проверенных преобразований исходного вопроса;
  - **k** — число преобразований, для которых ответ на преобразованный вопрос признан эквивалентным исходному ответу.
- Оценка корректности исходного ответа выполняется отдельно и **не используется** как метка устойчивости.

## Этапы пайплайна

1. **Data**: загрузка задач и генерация/сбор преобразований вопроса.
2. **Generation**: получение ответов фиксированной SLM с greedy decoding.
3. **Annotation**: оценка эквивалентности смыслов ответов и вычисление k/N.
4. **Modeling**: базовые предикторы и MLP для прогноза устойчивости.
5. **Evaluation**: метрики ошибок/ранжирования/калибровки и качественный анализ.

## Структура репозитория

- `configs/` — конфигурации экспериментов (в т.ч. пилот).
- `src/slm_answer_stability/`
  - `data/` — загрузка задач, преобразования, разделение выборок;
  - `generation/` — получение ответов SLM;
  - `annotation/` — сравнение смыслов и вычисление меток;
  - `models/` — базовые предикторы и MLP;
  - `evaluation/` — метрики и анализ.
- `scripts/` — команды вызова моделей и планируемые точки запуска этапов.
- `prompts/` — инструкции генератору преобразований и оценщику эквивалентности.
- `data/` — описание схемы, происхождения и версий данных + примеры.
- `results/` — правила сохранения конфигураций, таблиц и графиков.
- `paper/` — каркас статьи.
- `reviews/` — шаблон проверки ежедневного MVP.
- `tests/` — место для будущих тестов.
